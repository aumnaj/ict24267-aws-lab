คู่มือปฏิบัติการนี้เป็นเอกสารประกอบการเรียนวิชา Cloud Computing (ICT 24267) ซึ่งออกแบบเป็นโปรเจกต์ต่อเนื่องนาน 4 สัปดาห์ เพื่อให้นักศึกษาฝึกสร้างระบบบันทึกข้อมูลนักศึกษาบนแพลตฟอร์ม Amazon Web Services (AWS) เนื้อหาครอบคลุมตั้งแต่การตั้งค่าเซิร์ฟเวอร์จำลองด้วย EC2 การจัดการฐานข้อมูลผ่าน RDS ไปจนถึงการพัฒนาระบบแบบไร้เซิร์ฟเวอร์ด้วย Lambda และ API Gateway โดยเน้นการใช้ภาษา Python และเครื่องมือปรับแต่งประสิทธิภาพรวมถึงการรักษาความปลอดภัยที่หลากหลาย บทเรียนทั้งหมดถูกปรับแต่งให้ใช้งานภายใต้เงื่อนไข AWS Free Tier เพื่อส่งเสริมการเรียนรู้โดยไม่มีค่าใช้จ่าย พร้อมทั้งมีส่วนของแบบฝึกหัดและการสร้างแดชบอร์ดด้วย CloudWatch เพื่อติดตามการทำงานของระบบอย่างครบวงจร
